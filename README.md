# FORMAI model library

Asset hosting for the [FORMAI Quest 3 reference gallery](https://niemandx.github.io/formai/). The application and its controls live in [NieMandX/formai](https://github.com/NieMandX/formai).

The deployment downloads the exact models listed in `reference-assets.json` from the versioned FORMAI release and verifies their sizes and SHA-256 hashes before publishing. Each library is limited to 850 MiB of model assets.

The supplied reference scans are credited to Veiviev Limited, all rights reserved. Repository source-code availability does not grant a license to the scan assets.
